1. О ПРОГРАММЕ
--------------------------------------------------------------------------------
Eshkeri — это утилита с кастомным киберпанк-интерфейсом для выполнения квестов
Discord (Discord Quests / Orbs) и безопасной симуляции игровой активности.
Приложение запускает реальные изолированные игровые процессы с внутриигровым
оверлеем FPS, поддержкой Rich Presence и системного детекта Discord без
упоминаний сторонних протоколов.


2. КАК ПОЛЬЗОВАТЬСЯ ПРОГРАММОЙ
--------------------------------------------------------------------------------
Шаг 1: Запуск
  - Откройте приложение Discord на вашем компьютере.
  - Запустите файл Eshkeri.exe.

Шаг 2: Выбор или добавление игры
  - В главном списке выберите нужную игру (например, Cyberpunk 2077, Endnight
    Debuts Forest 3, Genshin Impact, Roblox, Where Winds Meet и др.).
  - Чтобы добавить новую игру, нажмите кнопку «➕ ДОБАВИТЬ НОВУЮ ИГРУ»:
    * Начните вводить название игры в поле поиска.
    * Появится список совпадений из официальной базы Discord (24 000+ игр).
    * Кликните по нужной игре — поля исполняемого файла (.exe) и Discord Client ID
      заполнятся автоматически.
    * Нажмите «💾 СОХРАНИТЬ В БАЗУ». Игра навсегда останется в вашем списке!

Шаг 3: Запуск симуляции квеста
  - Нажмите кнопку «▶ ЗАПУСК» напротив нужной игры.
  - Сработает анимация киберпанк-глича.
  - На рабочем столе откроется отдельное игровое окно с живым счетчиком FPS (144 FPS)
    и анимацией сканирующих линий.
  - В главном окне Eshkeri начнется обратный отсчет таймера (15:00).
  - В Discord сразу появится ваш статус: «Играет в [Название игры]».

Шаг 4: Завершение квеста и получение награды
  - Игровое окно симуляции можно свернуть (оно не мешает работе за ПК).
  - Через 15 минут программа уведомит вас о завершении квеста и остановит процесс.
  - Перейдите в Discord -> «Настройки пользователя» -> «Склад подарков» (Quests)
    и заберите вашу награду / Orbs!


3. ЧТО ДЕЛАТЬ, ЕСЛИ ДИСКОРД НЕ ОТОБРАЖАЕТ ИГРУ СРАЗУ
--------------------------------------------------------------------------------
Если при запуске симуляции статус «Играет в...» не отображается в вашем профиле:
  1. В Discord откройте: Настройки пользователя (шестеренка внизу) ->
     раздел «Конфиденциальность активности» (или «Зарегистрированные игры»).
  2. Убедитесь, что включен пункт: «Отображать текущую активность в статусе».
  3. Если игра не определилась автоматически, нажмите на ссылку:
     «Не видите свою игру? Добавьте её!»
  4. В списке запущенных окон выберите запущенное игровое окно и нажмите «Добавить».
  5. Discord навсегда зафиксирует игру, и теперь она будет отображаться автоматически.


4. ГДЕ ИСКАТЬ И КАК НАСТРОИТЬ ФОНОВОЕ ВИДЕО
--------------------------------------------------------------------------------
Если при запуске фоновое видео не появилось автоматически:

А) Основное расположение фонового видео:
   - Файл фонового видео должен называться:
     fonpril.mp4
   - Он должен лежать В ТОЙ ЖЕ САМОЙ ПАПКЕ, где находится файл Eshkeri.exe:
     C:\Users\МобайлМаркет\.gemini\antigravity\scratch\Eshkeri\fonpril.mp4
   - Если файл fonpril.mp4 находится рядом с Eshkeri.exe, программа
     автоматически подхватит его при старте.

Б) Запасные папки поиска:
   - Если в папке с .exe файла нет, программа ищет видео в папках:
     * C:\Users\[Имя]\Videos\opening cyberpunck.mp4
     * C:\Users\[Имя]\Videos\*.mp4
     * C:\Users\[Имя]\Downloads\*.mp4

В) Ручной выбор любого видео или картинки:
   - В верхней панели настроек программы нажмите кнопку:
     «📂 Выбрать»
   - Выберите ЛЮБОЕ видео (.mp4, .webm, .mkv, .avi) или картинку (.png, .jpg, .webp).
   - Выбранный фон моментально включится и сохранится в настройках (settings.json).

Г) Настройка прозрачности интерфейса:
   - Если видео или картинка перекрывается панелями программы, используйте ползунок:
     «👁 Прозрачность:»
   - Сдвиньте его влево (например, на 30–50%), чтобы сделать интерфейс стеклянным
     и четко видеть фоновое видео под кнопками.

Д) Настройка звука видео:
   - В верхней панели используйте ползунок «🔊 Звук:» для регулировки громкости
     или выставьте 0%, если хотите отключить звук видео.


5. ФАЙЛЫ СОХРАНЕНИЙ
--------------------------------------------------------------------------------
В папке с программой автоматически создаются файлы:
  - settings.json  — сохраняет громкость звука, прозрачность и путь к фону.
  - games_db.json  — сохраняет весь список игр и добавленные вами игры.
При перезапуске программы все ваши настройки и игры сохраняются!


6. МОБИЛЬНОЕ ПРИЛОЖЕНИЕ ДЛЯ ТЕЛЕФОНА (Android_App/Eshkeri.apk)
--------------------------------------------------------------------------------
Все файлы для телефона вынесены в отдельную удобную папку:
  📁 Android_App/
    ├── Eshkeri.apk (вес всего ~1.57 МБ, готовый к установке APK)
    └── ИНСТРУКЦИЯ_ANDROID.txt (подробное руководство)

А) Как установить на телефон:
   1. Скопируйте файл Eshkeri.apk из папки Android_App/ на телефон (через Telegram,
      USB-шнур, Discord или облачный диск Google/Яндекс).
   2. Откройте файл Eshkeri.apk на телефоне и нажмите «Установить»
      (разрешите установку из неизвестных источников в настройках безопасности).
   3. На экране появится ярлык с неоновой киберпанк-иконкой «Eshkeri Mobile».

Б) Режимы работы на телефоне:
   - Режим 1: «⚡ DISCORD GATEWAY» (Автономный спуфер прямо с телефона):
     * Позволяет выполнять квесты и транслировать статус «Играет в...»
       (ANIIMO GLOBAL LAUNCH, FORGOTTEN ISLAND, MARVEL RIVALS и др.)
       БЕЗ ВКЛЮЧЕНИЯ ПК!
     * Вставьте токен вашего Discord аккаунта и нажмите «ПОДКЛЮЧИТЬ».
     * Запустите нужную игру — статус моментально появится у всех ваших друзей.
     * Включает таймер на 15 минут со звуковым сигналом о выполнении квеста.
   - Режим 2: «📡 PC WI-FI BRIDGE» (Удаленный пульт для ПК):
     * Если программа Eshkeri.exe запущена на вашем ПК, телефон может управлять ей
       по домашней сети Wi-Fi!
     * Введите локальный IP вашего компьютера (например, 192.168.1.103:8888).
     * Запускайте и останавливайте симуляции на ПК со смартфона в один тап!
